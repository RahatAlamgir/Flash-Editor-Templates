# Flash Editor Templates

Templates for [Flash Editor](https://github.com/RahatAlamgir/Flash-Editor), downloaded by the app when a user picks one.

## Structure

    templates/            ready-made designs, one folder per project type
        youtube-thumbnail/  presentation/  poster/  card/
        instagram-post/     story/         flyer/   resume/
    elements/             icons, graphics, badges (planned)
    styles/               text looks (planned)
    docs/FORMAT.md        file format and rules (draft)
    types.json            the project types and their sizes
    keywords.json         the preferred search keywords (English)
    catalog.json          the list the app reads (made by a script)
    tools/make_templates/ the Python tool that makes template files from design scripts (see its README)
                          photos are public domain / CC0 from Wikimedia Commons; credits are in each catalog entry
    CHANGELOG.md          what changed in this repository

Empty folders hold a `.gitkeep` file so Git keeps them.
